# TestAS Mock Test System Context

This context defines the ubiquitous language for test taking, simulation, and targeted section practice in the TestAS preparation platform.

## Language

**Mock Exam**:
A complete, official test simulation comprising all required core and module sections taken sequentially with scheduled breaks under official time constraints.
_Avoid_: Test suite, full test, whole test

**Subtest Drill**:
An independent, timed test session structurally identical to a Mock Exam, executing the standard exam lifecycle and flow with a scoped subset of sections (one or more) under official timing constraints.
_Avoid_: Partial exam, mini exam, fragmented test, section drill

**Practice Bank**:
An untimed, flashcard-style study mode organized by subtest difficulty folders (easy, medium, hard) where students review questions, check solutions, and self-rate difficulty.
_Avoid_: Question bank, flashcards, drill bank

**Subtest**:
A specific academic subject area or question category within the TestAS format (e.g. *Solving Quantitative Problems*, *Visual 2D/3D*, *Depiction*).
_Avoid_: Category, subject, problem type

**Section**:
The database and structural instance of a Subtest belonging to a specific Mock Exam.
_Avoid_: Part, phase, module block

**Attempt**:
A tracked record of a user taking either a Mock Exam or a Subtest Drill, capturing user answers, timestamps, score, and completion status.
_Avoid_: Session, run, test log
